# 0.0.1 发布候选验证

本轮增加车机设置与 CowPlay 页内 Tesla 直达入口，整合 GitHub 检查／确认更新和首次 LuCI 引导安装。修复导入时固定授权码，以及随机码生成失败的固定码回退。首次发行使用 v0.0.1（APK 0.0.1-r0）。

本地组合版本：前端构建通过；Rust workspace 423 项通过，1 项现有外部 ACME 测试跳过；授权循环回归、Tesla 导航与 LuCI 更新实际 DOM 测试通过。包生命周期、恢复 helper 标签契约通过。独立代码评审发现的恢复标签遗漏已修复。

安装验证使用一次性 ARM64 Linux／OpenWrt 25.12.6 根、实际 APK、合成配置与本地 HTTPS GitHub 服务。最终发布命令的脚本哈希、公钥指纹、签名校验、下载、覆盖安装、私有状态／备份保留、后台运行、安装后 rpcd 状态恢复均通过。未使用跳过 TLS 或 APK 签名的安装选项。隔离测试根最初缺少运行时与随机设备节点，且首份合成证书不符合服务端证书约束；补齐真实运行条件后通过，初败保留在本地审查记录。

公开前专项审查覆盖现有 4 个提交、Actions 日志及构件、候选源码与实际签名附件。未发现真实私钥、访问令牌或私人设备状态；现场文档和私人 Git 历史不进入发布仓。已有默认授权码不会因覆盖安装被擅自替换，管理员应在设备与访问页轮换；已授权浏览器与手机配对保留。

未在现场访问 F50。本地和 CI 通过不代表真实 iPhone／车机／音频／长期稳定性验收。原生 CarPlay 图标慢或缺失尚未定位；网页图标已本地打包并修复类型、缓存，但二者不是同一个验收项。仓库仍由用户决定何时公开，匿名设备拉取需仓库公开。

# 0.0.1 发布候选验证

本轮增加车机设置与 CowPlay 页内 Tesla 直达入口，整合 GitHub 检查／确认更新和首次 LuCI 引导安装。访问流程改为首次在 CowPlay 自设接收端长期访问码；新浏览器必须验证，免验证和二维码准入已移除。首次发行使用 v0.0.1（APK 0.0.1-r0）。

访问码最终组合版本：前端构建通过；Rust workspace 427 项通过，1 项现有外部 ACME 测试跳过；首次设码、重复输入不一致、新浏览器错误码拒绝、禁止旧二维码绕过、记住浏览器，以及保存成功但 Cookie 未保存时的重试共 8 项实际 DOM 检查通过。原授权循环回归通过。Linux 安装器在全新默认状态目录初始化首次设码标记，既有状态保持不变；隔离安装测试通过。

更新器基础版本已通过 GitHub Actions 的 x86_64／ARM64 构建、Rust／浏览器测试、双 APK 安装和完整附件签名验证；该次 CI 早于本轮访问码修改，不能代替最终标签构建。Tesla 导航、LuCI 更新、包生命周期、恢复 helper 标签契约已有通过记录。独立评审指出的持久化失败锁定、Cookie 丢失后页面状态恢复与管理输入权限问题均已处理。

安装验证使用一次性 ARM64 Linux／OpenWrt 25.12.6 根、实际 APK、合成配置与本地 HTTPS GitHub 服务。最终发布命令的脚本哈希、公钥指纹、签名校验、下载、覆盖安装、私有状态／备份保留、后台运行、安装后 rpcd 状态恢复均通过。未使用跳过 TLS 或 APK 签名的安装选项。隔离测试根最初缺少运行时与随机设备节点，且首份合成证书不符合服务端证书约束；补齐真实运行条件后通过，初败保留在本地审查记录。

公开前专项审查覆盖发布仓源码、提交元数据、Actions 日志及构件、候选签名附件。未发现真实私钥、访问令牌或私人设备状态；现场文档和私人 Git 历史不进入发布仓。已有访问码不会因覆盖安装被替换，管理员可在设备与访问页修改或重置；已授权浏览器与手机配对保留。

未在现场访问 F50。本地和 CI 通过不代表真实 iPhone／车机／音频／长期稳定性验收。原生 CarPlay 图标慢或缺失尚未定位；网页图标已本地打包并修复类型、缓存，但二者不是同一个验收项。仓库保持私有，先完成私有 Release；匿名设备拉取需等公开。新提交的署名邮箱已改为 GitHub 隐私邮箱，但旧提交对象仍可通过 GitHub 读取，公开前必须另行完成服务器端清理并复核。当前源码和附件审查通过不代表这一元数据问题已解决。
